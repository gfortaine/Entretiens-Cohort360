# Technology Stack

## Core Architecture
- **Monorepo Management:** [Turborepo](https://turbo.build/)

## Frontend (apps/web)
- **Framework:** [React 19](https://react.dev/)
- **Language:** [TypeScript 5.9](https://www.typescriptlang.org/)
- **Build Tool:** [Vite](https://vitejs.dev/)
- **Styling:** [Tailwind CSS 4.1](https://tailwindcss.com/)
- **UI Components:** [Radix UI](https://www.radix-ui.com/), [Lucide React](https://lucide.dev/)
- **State Management & Data Fetching:** [TanStack Query v5](https://tanstack.com/query/latest)
- **API Client:** [Axios](https://axios-http.com/)
- **Forms:** [React Hook Form](https://react-hook-form.com/), [Zod](https://zod.dev/)
- **Internationalization:** [i18next](https://www.i18next.com/), [react-i18next](https://react.i18next.com/)
- **Testing:** [Vitest](https://vitest.dev/), [React Testing Library](https://testing-library.com/docs/react-testing-library/intro/)

## Backend (apps/api)
- **Framework:** [Django 5.2 LTS](https://www.djangoproject.com/)
- **API Toolkit:** [Django REST Framework (DRF)](https://www.django-rest-framework.org/)
- **Language:** [Python 3.12+](https://www.python.org/)
- **Package Manager:** [UV](https://github.com/astral-sh/uv)
- **Testing:** [Pytest](https://docs.pytest.org/), [Pytest-Django](https://pytest-django.readthedocs.io/)
- **Code Quality:** [Ruff](https://docs.astral.sh/ruff/), [MyPy](https://mypy-lang.org/)

## Data Engineering (Exercice_scala_spark)
- **Language:** [Scala 2.12](https://www.scala-lang.org/)
- **Data Processing:** [Apache Spark 3.3](https://spark.apache.org/)
- **Search Engine:** [Solr 8.11](https://solr.apache.org/)
- **Build Tool:** [SBT](https://www.scala-sbt.org/)
- **Testing:** [ScalaTest](https://www.scalatest.org/)

## End-to-End Testing
- **Framework:** [Playwright](https://playwright.dev/)
